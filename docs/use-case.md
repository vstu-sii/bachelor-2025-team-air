**Happy** **path** **(Основной успешный сценарий)**

1. HR загружает вакансию с описанием требований в систему

2. Кандидаты загружают свои резюме

3. AI-модуль анализирует резюме и требования вакансии

4. Система ранжирует кандидатов по степени соответствия

5. Для лучших кандидатов генерируются персональные вопросы

6. HR получает список кандидатов с рейтингом и вопросами

7. HR выбирает кандидатов для собеседования

Ценность:

- Экономия времени, снижение ошибок

- Уменьшение субъективности в отборе

- Быстрый доступ к подходящим кандидатам

**Alternative** **Flow** **(1): Неправильный ввод данных(неполные данные в резюме или вакансии)**

1. Система производит валидацию введенные данные

2. При обнаружении ошибки пользователю показывается подробное сообщение с рекомендацией

3. Пользователь исправляет данные и повторяет попытку

Ценность: Снижение ошибок при вводе, повышение качества данных

**Alternative** **Flow****(2): Частичная несовместимость резюме и вакансии**

1. Кандидат загружает резюме, которое соответствует только части требований вакансии

2. Система анализирует резюме и выявляет недостаточные или отсутствующие навыки

3. Вместо отказа система предлагает HR-менеджеру рассмотреть возможность обучения или адаптации кандидата

4. Для кандидата генерируются дополнительные вопросы, для выявления потенциала и мотивации

Ценность: Расширение пула кандидатов за счет выявления перспективных, но не полностью соответствующих соискателей; Помощь HR в принятии более гибких решений


**Error** **handling** **(1): Технический сбой** AI-модуля

1. Система уведомляет пользователя о временной недоступности функции

2. Автоматически регистрирует ошибку для техподдержки

3. Пользователь может повторить попытку позже

Ценность: сокращение времени простоя, повышение надежности

**Error** **handling** **(2): Формат резюме не поддерживается**

1. Система блокирует загрузку с сообщением о неподдерживаемом формате

2. Предлагает список поддерживаемых форматов

Ценность: Предотвращение ошибок загрузки, улучшение UX

**Error** **handling** **(3): Превышение лимита(Размера файла)**

1. Система предупреждает о превышенном размере

2. Предлагает инструкции по уменьшению файла

Ценность: Защита от перегрузки системы, стабильность работы
